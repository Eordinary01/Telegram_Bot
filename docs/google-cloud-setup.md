# Google Cloud provisioning placeholder

Google Cloud provisioning is part of Phases 1 and 2, not Phase 0. Before implementing provider-specific configuration, this guide will be expanded and checked against the current official Google documentation.

It will cover:

- Google Cloud project selection or creation
- OAuth consent screen in External/Test mode
- Pilot test users
- Gmail API enablement
- OAuth web client and callback URIs
- Pub/Sub topic and push subscription
- Gmail publisher IAM permission
- Authenticated push identity and audience validation
- Production HTTPS requirements

No Google credentials are required for the Phase 0 scaffold.
